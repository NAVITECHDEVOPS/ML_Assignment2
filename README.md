# ML_Assignment2

## Classifier Evaluation Lab

This project compares five classification methods on the Wisconsin Breast Cancer Diagnostic dataset, then evaluates a selected saved model in a Streamlit app. It is a learning project: rerun the experiment, inspect the code, and write your own interpretation before submitting it.

## Problem Statement

Classify a breast-mass sample as malignant or benign from its digitized cell-nucleus measurements. Missing a malignant case is an important error, so malignant is treated as the positive class when calculating precision, recall, F1, and AUC.

## Dataset Description

- **Dataset:** Wisconsin Breast Cancer Diagnostic (WDBC)
- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic)
- **Size:** 569 samples, 30 numeric input features, and one target column
- **Target:** `diagnosis`, with `malignant` and `benign` labels
- **Class counts:** 212 malignant and 357 benign samples
- **Use in this project:** The dataset is bundled with scikit-learn's public dataset collection. `train_models.py` exports a CSV copy to `data/breast_cancer.csv`.

The source contains no missing values in the bundled version. A stratified 80/20 split with random state 42 creates a training set of 455 rows and a held-out test set of 114 rows. Standardization is inside the Logistic Regression, KNN, and SVM estimators so it is learned from training data only.

## Models and Evaluation

All models use the same split. AUC uses the predicted probability for the malignant class. Precision, recall, and F1 also use malignant as the positive class. Values below were generated by `train_models.py` using scikit-learn 1.9.1; rerun the script and replace this table if your environment produces different values.

| Model | Accuracy | AUC | Precision | Recall | F1 | MCC |
|---|---:|---:|---:|---:|---:|---:|
| Logistic Regression | 0.965 | 0.996 | 0.975 | 0.929 | 0.951 | 0.925 |
| Decision Tree | 0.930 | 0.925 | 0.905 | 0.905 | 0.905 | 0.849 |
| K-Nearest Neighbors | 0.956 | 0.982 | 0.974 | 0.905 | 0.938 | 0.906 |
| Gaussian Naive Bayes | 0.939 | 0.993 | 1.000 | 0.833 | 0.909 | 0.871 |
| Support Vector Machine | 0.974 | 0.994 | 0.976 | 0.952 | 0.964 | 0.943 |

### Observations to Check Against Your Run

- **Logistic Regression:** Strong AUC and balanced performance on this split. It identifies 92.9% of malignant cases, with a small number of false positives.
- **Decision Tree:** Easiest to explain as rules, but it has the lowest AUC and MCC here. Its lower overall scores suggest the single tree does not generalize as well as the scaled models on this split.
- **K-Nearest Neighbors:** Performs well after scaling, but misses more malignant cases than Logistic Regression and SVM at the default five neighbors.
- **Gaussian Naive Bayes:** Its perfect precision means predicted malignant cases were correct in this test split, but recall of 83.3% means it misses more than the other strong models.
- **Support Vector Machine:** Best accuracy, recall, F1, and MCC in this run. Its 95.2% malignant recall is the highest of these models, while its AUC is close to the Logistic Regression result.
- **Current split winner:** Support Vector Machine, based on the highest accuracy, recall, F1, and MCC in this run. This is not proof it will be best on other splits or future samples; the 114-row test set is small.

Use the table as an experiment to interpret, not as text to submit unchanged. For example, compare the consequences of false negatives (malignant cases predicted benign) with false positives, and explain whether your model choice changes when recall matters more than precision.

## Run Locally

Use a virtual environment so the project dependencies do not conflict with packages used by other coursework:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python train_models.py
streamlit run app.py
```
